# 设计语言

LumenTray 的视觉方向是 **Light Desk**：一块暖石墨玻璃，上面放着几块被光照亮的屏幕。界面不是“控制面板”，而是一张桌面光线的缩略图；亮度滑杆是唯一主角。

相关文档：[架构](architecture.md) · [README](../README.md)

## 1. 设计立场

LumenTray 是一个两秒内完成“开窗—拖亮度—关窗”的工具，属于 Operate 场景。设计目标按优先级排列：

1. **读数先被看见。** 百分比是用户唯一要确认的信息，必须比装饰更醒目。
2. **窗口像有厚度的玻璃。** 外壳承担材质、光线和深度；内容面保持实心、清楚。
3. **视觉资源集中给滑杆。** 强调色只服务滑杆、焦点与当前选中项。
4. **安静。** 没有常驻动画、没有流动高光、没有装饰性光斑。

明确不做：

- 不做 SVG `feDisplacementMap` 折射：WebView2 采样昂贵，收益低。
- 不把玻璃叠在卡片和按钮上：一层玻璃外壳 + 实心内容面。
- 不做全透明模式：不透明度下限 85%，保证可读性。
- 不为“高级感”牺牲操作速度：不使用低对比度灰字或过小点击目标。

## 2. 材质分层

| 层 | 角色 | 实现 | 规则 |
|---|---|---|---|
| L0 | 桌面 | 原生 DWM | 窗口透明、无原生阴影、不启用 Mica |
| L1 | 外壳玻璃 | `.flyout` / `.settings` / `.osd`：tint + `backdrop-filter` + 顶部内高光 + 外阴影 | 全局只有这一层 blur |
| L2 | 内容面 | 总控、显示器组、设置卡片、日志槽 | 半实心、无 blur、1 px hairline |
| L3 | 控件 | 滑杆、开关、分段、按钮 | 明确悬停、按下、焦点态 |
| L4 | 强调 | 滑杆已填充轨道、焦点环、导航指示条 | 面积受控，不做图标底色 |

`backdrop-filter` 视为渐进增强：即使 WebView2 透明窗口下不生效，tint、高光与阴影仍应成立，文字对比不依赖 blur。

### 2.1 窗口构造

- 飞窗与设置窗使用 `transparent(true)` + `shadow(false)` + 不启用 Mica。
- 窗口四周留 20 px 透明 gutter（`--window-pad`），CSS 只在 gutter 以内绘制圆角外壳与阴影。
- 原因：Mica 会铺满整个窗口矩形并被 DWM 框住，圆角外会出现一圈系统描边或月牙；原生阴影也会对矩形再画一圈边框。
- 透明度由 `--glass-alpha` 控制，shell tint 的 RGB 按主题固定，alpha 来自用户设置。


### 3.2 字体角色

字体系统不是按“元素”分配，而是按**信息角色**分配：

| 角色 | 字体 | 用途 |
|---|---|---|
| 读数 | Newsreader 衬线，数字子集 | 飞窗总控 / 行值、设置显示器卡、透明度芯片、OSD、“上次”记录值 |
| 词句 | Inter + HarmonyOS Sans SC / Noto Sans SC | 标题、标签、状态、说明、句内数量词 |
| 标识 | Cascadia Mono / Consolas | 行号、页面编号、路径、快捷键、版本号、错误码 |

Newsreader 只保留 `0123456789%.`，woff2 约 12 KB，随包分发（OFL 1.1）。Inter 与 Noto Sans SC 也是随包字体；系统提供 HarmonyOS Sans SC 时优先使用。

**只有读数用衬线。** 标签、正文与状态说明保持无衬线，避免整页变成杂志；行号、路径与键位保持等宽，因为它们是面板标识，不是测量值。

### 3.3 读数规格

| 位置 | 字号 / 字重 | 单位字号 | 单位抬升 |
|---|---|---|---|
| 飞窗总控 | 30px / 500 / `-0.005em` | 12.5px / 450 | `top: -13px` |
| 飞窗行值 | 18px / 500 / `-0.005em` | 11px / 450 | `top: -7.5px` |
| 设置显示器卡 | 21px / 500 / `-0.005em` | 11.5px / 450 | `top: -8px` |
| OSD | 28px / 500 / `-0.005em` | 11.5px / 450 | `top: -12px` |
| 飞窗「上次」 | 13px / 500 | 8.5px / 450 | 上标 |
| 设置「上次」 | 14px / 500 | 9px / 450 | 上标 |
| 透明度芯片 | 14px / 500 | 9px / 450 | 上标，芯片高 24 px 垂直居中 |

- 单位一律用 `position: relative` 抬升，不嵌套子元素，不改变 flex baseline。
- `90`、`100`、`—` 三种读数切换时行宽与基线稳定。
- 实时值与历史值只靠字号和颜色分层，不换字族：行 18 → 上次 13；设置 21 → 上次 14；`--text` → `--text-secondary`。
- 单位颜色保持 `--text-tertiary`；滑杆激活时混入暖色。

深色：

```css
--text: #f5efe5;
--text-secondary: #bbb2a4;
--text-tertiary: #a0988b;
--accent: #f0c58e;
--accent-bright: #ffdcae;
--accent-text: #f2d0a2;
--accent-soft: rgba(255, 205, 150, 0.15);
--success: #7bcf9f;
--warning: #edb27a;
--danger: #ff9c92;
--track: rgba(255, 236, 210, 0.16);
--hairline: rgba(255, 236, 208, 0.12);
```

外壳 tint：

| 主题 | 默认（95%） | 说明 |
|---|---|---|
| 浅色 | `rgba(244, 238, 228, 0.95)` | 暖象牙纸感 |
| 深色 | `rgba(16, 15, 17, 0.95)` | 暖石墨 |

不透明度可在 85%–100% 之间调节，默认 95%。85% 最透，壁纸存在感强；100% 为实色，适合强光或弱视环境。系统「减少透明度」会覆盖用户设置，固定到 0.985。

### 3.5 光图

显示器光图是飞窗的核心插图：

- 深色舞台（`--stage-bg`）上按真实分辨率与相对位置排布屏幕。
- 每块屏幕内部有跟随亮度变化的暖光渐变，亮度越高，光越亮。
- 不可控屏幕不发光，使用斜纹底与警告标记，但仍保留编号和位置。
- 标题「桌面光图」与不可控说明使用小号无衬线；编号使用等宽。

光图不是装饰，它回答“这块滑杆对应哪块屏”。多屏位置异常时，用户仍能通过编号、名称和接口确认目标。

## 4. 窗口规格

### 4.1 飞窗

- 逻辑内容宽度 380 px；窗口含 20 px gutter，实际窗口 420 px。
- 高度由前端内容上报后 `resize_flyout` 调整，v5.1 实测内容高 618.14 px。
- 结构：标题栏 → 桌面光图 → 全部显示器总控 → 单屏列表 → 底部状态。
- 行高 75 px；不可控行在行内展开错误提示与「重试」按钮。
- 底部左侧「DDC/CI 本地控制」，右侧「步进 N%」。
- 失焦或 `Esc` 关闭；打开设置时先创建设置窗再关闭飞窗。

### 4.2 设置窗

- 逻辑内容 720 × 560，含 gutter 后 760 × 600。
- 左侧导航 200 px；右侧内容列 466 px；诊断页因日志与长路径使用 1253 px 的滚动内容。
- 五页：通用、快捷键、显示器、诊断、关于。
- 页面标题 24 px，右侧英文页签 + 编号（`GENERAL 01 / 05`）使用等宽。
- 设置分组使用「竖条 + 标题 + 分隔线」，卡片圆角 14 px。
- 修改即时生效；外观类设置拖动时实时预览，松手落盘。

### 4.3 OSD

- 窗口 400 × 128，位于鼠标所在显示器顶部居中，上边距 16 px。
- 胶囊内容：显示器编号、名称、主屏标记、同步文案、百分比、细进度条。
- 1.6 s 后淡出 240 ms；窗口 30 s 空闲后销毁。
- 不抢焦点、不进任务栏与 `Alt` + `Tab`、鼠标穿透。
- 显示器无响应时读数为「—」，进度条为虚线，并提示实际同步台数。

## 5. 控件与状态

- **滑杆**：6 px 轨道、17 px 拇指，已填充部分使用暖色渐变；拇指有内外两层高光。键盘方向键按用户设置的步长，`PgUp` / `PgDn` 固定 10%，`Home` / `End` 到 0 / 100。
- **开关**：轨道与拇指都有按下位移；关闭态使用低对比轨道，开启态使用暖色。
- **分段控件**：浅色下为半透明底 + 选中白面；深色下为低亮底 + 选中亮面。
- **导航**：激活项左侧有暖色竖条，切换时竖条生长，内容区淡入。
- **状态**：使用「圆点 + 文字」而非彩色胶囊；可调为绿色，异常为琥珀色。
- **失败**：卡片保留，读数改为「上次 N%」并使用次级色；原因在行内展开，附带「重试」。
- **空状态**：没有显示器时显示说明与重新检测入口，不显示空白列表。
- **加载**：首次加载使用骨架；已有快照时先显示快照，再静默刷新。

## 6. 动效

| 场景 | 规格 |
|---|---|
| 飞窗入场 | opacity 120 ms + translateY 8 px→0 320 ms，`cubic-bezier(0.16, 1, 0.3, 1)` |
| 页面切换 | 内容淡入 190 ms |
| 滑杆填充 | 120 ms |
| 开关 / 按钮 | 120 ms 按压反馈 |
| OSD 淡出 | 240 ms |

- 动画只在 `reveal` 之后启动；窗口隐藏阶段不提前播放，避免首开“顿”。
- `prefers-reduced-motion: reduce` 时移除位移动画与淡入，只保留最终状态。

## 7. 无障碍

- 滑杆带 `aria-label` 与 `aria-valuetext="N%"`；图标按钮带中文 `aria-label`。
- 键盘可达：滑杆、开关、分段、导航、重试均可聚焦；焦点环使用暖色高对比。
- `prefers-contrast: more`：提高次级文字、hairline 与轨道对比度。
- `forced-colors: active`：使用系统颜色，去掉背景装饰与阴影。
- `prefers-reduced-transparency: reduce`：外壳接近实色，保证可读性。
- DPR 1 与 DPR 2 均验证 1 px 描边与字体清晰度；4K 200% 下不手动缩放 WebView。

## 8. 验收基线

v5.1 在 release 构建上核对：

- 飞窗内容高 618.14、行高 75、「上次」读数 13 px。
- 设置五页内容列 466 px，诊断页 1253 px。
- 透明度芯片保持 24 px 高，数字垂直居中。
- 深浅色、DPR 1 / 2、100% 三位数、OSD 90% / 100% / 无响应三态均截图核对。
- 启动、失焦关闭、`Esc`、托盘切换、设置窗切换均无闪回或重复窗口。

## 9. 禁止项

- 不在卡片或按钮上再叠 `backdrop-filter`。
- 不启用 Mica 或原生窗口阴影来“补”玻璃质感。
- 不给正文或标签使用衬线字体。
- 不把读数降回小号无衬线来“统一”。
- 不使用常驻动画、呼吸光、流动高光。
- 不用低于 85% 的玻璃不透明度换取“更透”的观感。
- 不为装饰增加新的字号层级；新读数先归入现有三档。
